# website-promocao-3d
A Promoção 3D é uma política pública de conscientização que atua nas três dimensões da doação humana — sangue, órgãos e leite humano. Criada por pesquisadores da Universidade de Pernambuco (UPE), promove educação, empatia e solidariedade, combatendo mitos e incentivando as doações que salvam vidas.
